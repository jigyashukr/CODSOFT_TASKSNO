# CODSOFT Internship Tasks

This repository contains the projects completed as part of my **CODSOFT Internship** in Artificial Intelligence and Machine Learning.

## 📌 Tasks

### Task 1 — Rule-Based Chatbot

A simple chatbot developed using Python that responds to user inputs based on predefined rules and keyword matching.

**Concepts Used:**

* Python
* If-Else Statements
* Pattern Matching
* Basic Natural Language Processing (NLP)
* Conversation Flow

**File:** `Task_1_Rule_Based_Chatbot.ipynb`

---

### Task 2 — Movie Recommendation System

A simple content-based movie recommendation system that recommends movies based on their genres.

The system uses **TF-IDF vectorization** and **Cosine Similarity** to identify movies with similar characteristics.

**Concepts Used:**

* Python
* Pandas
* Content-Based Filtering
* TF-IDF
* Cosine Similarity
* Recommendation Systems

**File:** `Task_2_Movie_Recommendation_System.ipynb`

---

### Task 3 — Tic-Tac-Toe AI

An AI agent that plays the classic Tic-Tac-Toe game against a human player.

The AI uses the **Minimax algorithm with Alpha-Beta Pruning** to evaluate possible moves and select an optimal move.

**Concepts Used:**

* Python
* Game Theory
* Minimax Algorithm
* Alpha-Beta Pruning
* Search Algorithms
* Artificial Intelligence

**File:** `Task_3_Tic_Tac_Toe_AI.ipynb`
